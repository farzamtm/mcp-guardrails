# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to issues, pull requests, discussions and any other project space.

In short: be respectful, assume good faith, critique code rather than people,
and keep harassment, personal attacks and discriminatory language out of it.

## Reporting

Report unacceptable behaviour privately to the maintainer at
<farzamit@gmail.com>. Reports are read by the maintainer only and handled
confidentially. The maintainer may remove comments, close threads or block
participants who do not follow this code, as described in the Covenant's
enforcement guidelines.

Security vulnerabilities are not conduct issues; report those as described in
[SECURITY.md](SECURITY.md).
